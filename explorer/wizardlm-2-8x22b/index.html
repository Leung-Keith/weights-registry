WizardLM-2-8x22B is a large language model released by Microsoft, released under the apache-2.0 license, with a claimed knowledge cutoff of 2024-04-30. Its weights, configuration, and tokenizer files have been cryptographically hashed and are queued for on-chain attestation by Weight Registry.

Description

WizardLM-2 8x22B, Microsoft AI's most advanced Wizard model at release, demonstrating highly competitive performance vs leading proprietary models and outperforming existing open-source models. Microsoft removed the original repo within hours of release (cited missing toxicity testing); this entry hashes the community-preserved mirror, which is itself a case study in why an immutable weight registry matters.
