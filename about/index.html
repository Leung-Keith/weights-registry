About Weight Registry

A permissionless, blockchain-anchored registry that cryptographically hashes and timestamps open-source AI model weights — so anyone can later prove a specific model existed, unmodified, at a specific time, without having to trust the entity making that claim.

The problem

Open-source AI model weights are typically hosted on platforms like Hugging Face, where a repository can be silently edited, re-uploaded, renamed, or taken down entirely. There's no independent record of exactly which bytes were published, by whom, or when. That gap matters more than it looks: model provenance disputes, "who trained on what" copyright questions, and claims about what a model could or couldn't have known at a given date all currently rely on trusting whoever is making the claim — a hosting platform, a company's blog post, or a screenshot.

Weight Registry replaces that trust requirement with a cryptographic one. Anyone can independently recompute a model's hash from the same public files and check it against the on-chain record — no permission, account, or intermediary needed.

How it works

For each model, the registry computes multiple hash digests (SHA-256, SHA3-256, and BLAKE3) over the weights, config, and tokenizer files. For models split across multiple shard files, a domain-separated Merkle tree is built over the shard hashes first, so the root still proves every byte of every shard. Those file-level hashes are then combined into one commitment per algorithm using the same Merkle construction.

That commitment, along with the model's name, issuer, source URL, source revision, and claimed knowledge cutoff, is sealed into a permanent, non-revocable attestation using the Ethereum Attestation Service (EAS) — a public, on-chain schema built for exactly this kind of structured, verifiable claim.

Hashing
SHA-256, SHA3-256, BLAKE3 — three independent algorithms, so a collision in one wouldn't compromise the proof.
Combining
Domain-separated Merkle tree over weights + config + tokenizer hashes (and over shard hashes first, for sharded models).
Anchoring
EAS attestations on Ethereum, revocable: false at the schema level — once minted, a record cannot be revoked or altered by anyone, including us.
Verification
Fully independent: recompute the hash from the public files yourself, then compare it against the on-chain attestation via EAS's public explorer. No account or API key required.

Use cases

§

Legal & IP disputes

Establish, with cryptographic evidence rather than a hosting platform's word, that a specific set of weights existed in a specific form by a specific date — relevant to copyright, trade secret, and priority disputes.

◷

Historical & research verification

A model's knowledge cutoff is an accidental witness to what was publicly known by a given date. An on-chain, tamper-evident record of that cutoff makes the witness trustworthy enough to cite.

✓

Provenance & integrity audits

Confirm that a downloaded checkpoint's bytes match what was originally published — rather than a silently modified, backdoored, or swapped file with the same name.

⑂

Fine-tuning attribution

Verify the exact base checkpoint a derivative or fine-tuned model claims to descend from, instead of relying on an unverifiable README claim.

⌘

Compliance recordkeeping

Give organizations subject to emerging AI regulation an immutable, third-party-verifiable audit trail of exactly which model version was deployed and when.

✎

Journalism & fact-checking

Let reporters independently verify a vendor's claims about when a model was trained or what information it could plausibly have had access to.

Why permissionless, why blockchain

The point of anchoring this on a public blockchain rather than, say, a company database or a notarized PDF, is that no single company, government, or platform controls the record or can quietly edit it later. Verification doesn't require asking us, trusting us, or even the registry still existing as a project — the attestations live on-chain independently of any one party's continued cooperation.

Current status

The registry is currently deployed on Sepolia, Ethereum's public testnet, during this project's initial build-out. The hashing and attestation mechanics are identical to what would run on Ethereum mainnet — moving is a configuration change, not a redesign.
